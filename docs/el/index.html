NativeVoice

Η υπαγόρευση δεν σταματά στα αγγλικά.

Κράτα πατημένο ένα πλήκτρο, μίλα, άφησέ το — το κείμενο εμφανίζεται εκεί όπου είναι ο δρομέας σου. Η υπαγόρευση σε Mac είναι εξαιρετική στα αγγλικά και αποσπασματική ή ανύπαρκτη σε όλα τα άλλα. Αυτό είναι φτιαγμένο ανάποδα.

Βασισμένο στο API ElevenLabs Scribe — δοκιμασμένο απέναντι στις εναλλακτικές ακριβώς στις γλώσσες για τις οποίες υπάρχει, και το μόνο που τα κατάφερε. Αξιόπιστα και αρκετά σωστά ώστε να το εμπιστεύεσαι.

Λήψη για macOS GitHub

Δωρεάν · ανοιχτός κώδικας · macOS 13+ · Apple silicon και Intel

Δικά σου λόγια

Ονόματα και εξειδικευμένοι όροι είναι αυτό που η μεταγραφή κάνει λάθος. Ένα απλό αρχείο κειμένου με τους όρους σου, που διαβάζεται πριν από κάθε μεταγραφή.

Τίποτα δεν κρατιέται

Ο ήχος διαγράφεται μόλις μεταγραφεί. Το ιστορικό είναι απενεργοποιημένο μέχρι να το ενεργοποιήσεις, και η απενεργοποίησή του διαγράφει όσα είχαν αποθηκευτεί.

Όλα σε ένα μενού

Δεν υπάρχει παράθυρο ρυθμίσεων για να ψάχνεις. Όσα κάνει η εφαρμογή, τα κάνει από εδώ — και όσα βλέπεις είναι όλα όσα υπάρχουν.

Γλώσσα, πλήκτρο ενεργοποίησης, όριο εγγραφής και το λεξιλόγιό σου· ήχοι, αυτόματη επικόλληση και αφαίρεση γεμισμάτων· η χρήση σου στην ElevenLabs έναντι του ορίου της· και το αρχείο καταγραφής, που εξηγεί με απλές προτάσεις τι έκανε η εφαρμογή και γιατί.

Πώς να το ρυθμίσεις

Δέκα λεπτά. Φέρνεις το δικό σου κλειδί από την ElevenLabs: πληρώνεις απευθείας εκείνους για όσα υπαγορεύεις και τίποτα δεν περνάει από κανέναν άλλο. Το δωρεάν πλάνο τους είναι 10.000 credits τον μήνα και η μεταγραφή κοστίζει 330 credits το λεπτό — περίπου μισή ώρα υπαγόρευσης κάθε μήνα τζάμπα. Έλεγξε την τρέχουσα τιμολόγησή τους πριν βασιστείς σε αυτό.

  1. Σύρε το NativeVoice στις Εφαρμογές και άνοιξέ το. Δεν έχει παράθυρο· ψάξε το στη γραμμή μενού.

  2. Φτιάξε ένα κλειδί στο ElevenLabs → Settings → API Keys και αντιγράψε το αμέσως — το δείχνουν μόνο την πρώτη φορά.

  3. Μενού → ElevenLabs account → Set API key… → επικόλληση → Save.

  1. Πες ναι όταν ζητήσει microphone, Input Monitoring και Accessibility. Τα παράθυρα διαλόγου εμφανίζονται μόνα τους· δεν χρειάζεται να τα ψάξεις.

  2. Άφησέ το να κάνει restart όταν το προτείνει. Το macOS δίνει το Input Monitoring μόνο σε μια διαδικασία που μόλις ξεκίνησε, οπότε τίποτα δεν δουλεύει μέχρι τότε.

  3. Κράτα το δεξί ⌘ και μίλα.
