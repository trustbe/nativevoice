NativeVoice

ಇಂಗ್ಲಿಷ್‌ಗೆ ಸೀಮಿತವಾಗದ ಡಿಕ್ಟೇಷನ್.

ಒಂದು ಕೀಯನ್ನು ಒತ್ತಿ ಹಿಡಿಯಿರಿ, ಮಾತನಾಡಿ, ಬಿಡಿ — ನಿಮ್ಮ ಕರ್ಸರ್ ಇರುವಲ್ಲಿ ಪಠ್ಯ ಕಾಣಿಸುತ್ತದೆ. Mac ನಲ್ಲಿ ಡಿಕ್ಟೇಷನ್ ಇಂಗ್ಲಿಷ್‌ನಲ್ಲಿ ಅತ್ಯುತ್ತಮವಾಗಿದೆ, ಆದರೆ ಇತರ ಎಲ್ಲ ಭಾಷೆಗಳಲ್ಲಿ ಅಸಮರ್ಪಕ ಅಥವಾ ಇಲ್ಲವೇ ಇಲ್ಲ. ಇದು ನಿರ್ಮಿಸಲ್ಪಟ್ಟಿದ್ದು ಇದಕ್ಕೆ ವಿರುದ್ಧ ದಿಕ್ಕಿನಲ್ಲಿ.

ElevenLabs Scribe API ಆಧಾರಿತ. ನಾನು ನಿಜವಾಗಿ ಡಿಕ್ಟೇಟ್ ಮಾಡುವ ಭಾಷೆಗಳಲ್ಲಿ ಪರ್ಯಾಯಗಳನ್ನು ಪ್ರಯತ್ನಿಸಿದೆ, ಮತ್ತು ಇದು ಅವುಗಳನ್ನು ಸರಿಯಾಗಿ ಗ್ರಹಿಸಿದ ಒಂದೇ ಆಯ್ಕೆ — ವಿಶ್ವಾಸಾರ್ಹವಾಗಿ, ಮತ್ತು ನಂಬಲು ಸಾಕಷ್ಟು ನಿಖರವಾಗಿ. ಇದರ ವೆಚ್ಚ ಕೆಲವೇ ಸೆಂಟ್‌ಗಳು.

ಎಲ್ಲವೂ ಒಂದೇ ಮೆನುವಿನಲ್ಲಿ

ಹುಡುಕಾಡಲು ಸೆಟ್ಟಿಂಗ್ಸ್ ವಿಂಡೋ ಇಲ್ಲ. ಈ ಆಪ್‌ಗೆ ಏನು ಮಾಡಲಾಗುತ್ತದೆಯೋ, ಅದನ್ನು ಇಲ್ಲಿಂದಲೇ ಮಾಡುತ್ತದೆ — ಮತ್ತು ನೀವು ಕಾಣುವುದೇ ಎಲ್ಲವೂ.

ಭಾಷೆ, ಟ್ರಿಗರ್ ಕೀ, ರೆಕಾರ್ಡಿಂಗ್ ಮಿತಿ ಮತ್ತು ನಿಮ್ಮ ಪದಕೋಶ; ಧ್ವನಿಗಳು, ಸ್ವಯಂಚಾಲಿತ ಪೇಸ್ಟಿಂಗ್ ಮತ್ತು ಫಿಲ್ಲರ್ ಪದಗಳ ತೆಗೆಯುವಿಕೆ; ನಿಮ್ಮ ಮಿತಿಗೆ ಹೋಲಿಸಿ ElevenLabs ಬಳಕೆ; ಮತ್ತು ಆಪ್ ಏನು ಮಾಡಿತು ಮತ್ತು ಏಕೆ ಎಂಬುದನ್ನು ಸರಳ ವಾಕ್ಯಗಳಲ್ಲಿ ವಿವರಿಸುವ ಲಾಗ್.

ಇದನ್ನು ಸಿದ್ಧಪಡಿಸುವುದು

ಹತ್ತು ನಿಮಿಷ. ನಿಮ್ಮದೇ ElevenLabs ಕೀ ತರುತ್ತೀರಿ: ನೀವು ಡಿಕ್ಟೇಟ್ ಮಾಡಿದ್ದಕ್ಕೆ ನೇರವಾಗಿ ಅವರಿಗೆ ಪಾವತಿಸುತ್ತೀರಿ ಮತ್ತು ಇನ್ನಾರ ಮೂಲಕವೂ ಏನೂ ಹೋಗುವುದಿಲ್ಲ. ಅವರ ಉಚಿತ ಯೋಜನೆ ಮಾಸಿಕ 10,000 ಕ್ರೆಡಿಟ್‌ಗಳು ಮತ್ತು ಟ್ರಾನ್‌ಸ್ಕ್ರಿಪ್ಷನ್‌ಗೆ ನಿಮಿಷಕ್ಕೆ 330 ಕ್ರೆಡಿಟ್‌ಗಳು ಬೇಕಾಗುತ್ತವೆ — ಅಂದರೆ ಪ್ರತಿ ಮಾಸ ಸುಮಾರು ಅರ್ಧ ಗಂಟೆ ಉಚಿತ ಡಿಕ್ಟೇಷನ್. ಇದನ್ನು ನಂಬುವ ಮೊದಲು ಅವರ ಪ್ರಸ್ತುತ ಬೆಲೆಗಳನ್ನು ಪರಿಶೀಲಿಸಿ.

  1. NativeVoice ಅನ್ನು Applications ಗೆ ಎಳೆದು ತೆರೆಯಿರಿ. ಇದಕ್ಕೆ ವಿಂಡೋ ಇಲ್ಲ; ಮೆನು ಬಾರ್‌ನಲ್ಲಿ ಹುಡುಕಿ.

  2. ElevenLabs → Settings → API Keys ನಲ್ಲಿ ಕೀ ತಯಾರಿಸಿ ಮತ್ತು ಕೂಡಲೇ ಕಾಪಿ ಮಾಡಿ — ಅವರು ಅದನ್ನು ಮೊದಲ ಬಾರಿಗೆ ಮಾತ್ರ ತೋರಿಸುತ್ತಾರೆ.

  3. ಮೆನು → ElevenLabs account → Set API key… → ಪೇಸ್ಟ್ → Save.

  1. ಇದು microphone, Input Monitoring ಮತ್ತು Accessibility ಕೇಳಿದಾಗ ಹೌದು ಎನ್ನಿ. ಅದು ತಾನೇ ಡೈಲಾಗ್‌ಗಳನ್ನು ತೋರಿಸುತ್ತದೆ; ನೀವು ಹುಡುಕಬೇಕಾಗಿಲ್ಲ.

  2. ಅದು ಕೇಳಿದಾಗ restart ಮಾಡಲು ಬಿಡಿ. macOS Input Monitoring ಅನ್ನು ಹೊಸದಾಗಿ ಪ್ರಾರಂಭಿಸಿದ ಪ್ರಕ್ರಿಯೆಗೆ ಮಾತ್ರ ನೀಡುತ್ತದೆ, ಆದ್ದರಿಂದ ಅದು ಆಗುವವರೆಗೆ ಏನೂ ಕೆಲಸ ಮಾಡುವುದಿಲ್ಲ.

  3. ಬಲ ⌘ ಅನ್ನು ಒತ್ತಿ ಹಿಡಿದು ಮಾತನಾಡಿ.
