NativeVoice

Sanelu, joka ei pääty englantiin.

Pidä näppäintä painettuna, puhu, päästä irti — teksti ilmestyy kursorin kohdalle. Sanelu Macilla on erinomaista englanniksi ja puutteellista tai olematonta kaikessa muussa. Tämä on rakennettu toisin päin.

Rakennettu ElevenLabs Scribe -rajapinnan varaan — vertailtu vaihtoehtoihin juuri niillä kielillä, joita varten tämä on, ja ainoana se osui oikeaan. Luotettavasti ja riittävän tarkasti, että siihen voi luottaa.

Yksi ele

Pidä oikeaa Command-näppäintä painettuna, puhu, päästä irti. Ei ikkunaa opeteltavaksi, ei tilaa käynnistettäväksi, ei mitään klikattavaa ensin.

Oma avaimesi

ElevenLabs-avaimesi, tallennettuna macOS-avainnippuun, eikä sitä näytetä enää koskaan. Maksat suoraan heille siitä, mitä sanelet.

🔍

Omat sanasi

Nimet ja erikoistermit ovat se, missä litterointi menee pieleen. Yksinkertainen tekstitiedosto termeistäsi, luettu ennen joka sanelua.

🔒

Mitään ei säilytetä

Äänite poistetaan heti, kun se on litteroitu. Historia on pois päältä, kunnes kytket sen päälle, ja pois päältä kytkeminen poistaa sen, mitä oli tallennettu.

Avoin ja allekirjoitettu

MIT, noin 3 500 riviä, ei riippuvuuksia. Allekirjoitettu ja notarisoitu, ja se päivittää itsensä — ei koskaan saneltaessa.

Kaikki yhdessä valikossa

Ei asetusikkunaa, jossa pitäisi penkoa. Sen, mitä sovellus osaa, se tekee täältä — ja se, mitä näet, on kaikki.

Kieli, laukaisunäppäin, tallennuksen enimmäispituus ja sanastosi; äänet, automaattinen liittäminen ja täytesanojen poisto; ElevenLabs-käyttösi suhteessa rajaan; ja loki, joka selittää yksinkertaisin lausein, mitä sovellus teki ja miksi.

Käyttöönotto

Kymmenen minuuttia. Tuot oman ElevenLabs-avaimesi: maksat suoraan heille siitä, mitä sanelet, eikä mikään kulje kenenkään muun kautta. Heidän ilmainen tasonsa on 10 000 krediittiä kuukaudessa, ja litterointi maksaa 330 krediittiä minuutilta — noin puoli tuntia sanelua ilmaiseksi kuukaudessa. Tarkista heidän nykyiset hintansa ennen kuin luotat siihen.

  1. Vedä NativeVoice Ohjelmat-kansioon ja avaa se. Siinä ei ole ikkunaa; etsi se valikkopalkista.

  2. Luo avain osoitteessa ElevenLabs → Settings → API Keys ja kopioi se saman tien — se näytetään vain ensimmäisellä kerralla.

  3. Valikko → ElevenLabs account → Set API key… → liitä → Save.

  1. Vastaa kyllä, kun se kysyy mikrofonia, Syötteen tarkkailua ja Käyttöapua. Se nostaa ikkunat itse esiin; sinun ei tarvitse etsiä niitä.

  2. Anna sen käynnistyä uudelleen, kun se tarjoutuu siihen. macOS antaa Syötteen tarkkailun vain juuri käynnistetylle prosessille, niin ettei mikään toimi ennen sitä.

  3. Pidä oikeaa ⌘ painettuna ja puhu.
